# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Overview

Unattended Windows ETL job: logs into a corporate Spotfire portal with Selenium, downloads the "DDA" report (vehicles delivered by dealers to end customers) as Excel, filters it with pandas, and loads new VINs into SQL Server. Code, identifiers, log messages and docs are in Spanish — keep new code consistent with that.

## Commands

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requerimientos.txt
python main.py                  # runs the full pipeline (needs .env, portal access and SQL Server)
pyinstaller --onefile main.py   # production build, deployed as a Windows scheduled task
```

There are no tests, linter config, or CI. The only way to exercise the pipeline end-to-end is a real run against the portal and database.

`requerimientos.txt` is UTF-16 LE encoded (generated by `pip freeze >` in PowerShell). Preserve that encoding when editing it, or convert it deliberately.

## Architecture

Layered (MVC-ish) structure; each class reads its own config from environment variables via `os.getenv` in `__init__`, so `.env` must be loaded (done in `main.py`) before any class is instantiated.

Call flow:

1. `main.py` → `load_dotenv(resource_path(".env"))` → `etl_dda_controlador.procesar_reporte_dda()`
2. `controlador/lectura_archivo_controlador.py` retries `ClienteSelenium.descargar_archivo_dda()` up to `INTENTOS_DESCARGA` times. That method returns a dict `{"estado": bool, "error"?: str}` instead of raising.
3. `infraestructura/cliente_selenium.py` drives Chrome: login (IPN → next → choose password → password → verify), then double-clicks through 7 folder XPaths (`_navegar_carpetas`), switches to the new window, and exports the report via context menu into `DESCARGA_REPORTE`. Uses `ChromeDriverManager`, falling back to the local `RUTA_WEBDRIVER`. Some XPaths are hardcoded absolute paths in the method body. The rest come from env vars. Flow pacing relies on fixed `time.sleep` constants (`_WAIT_*`) plus `*_click_safe` retries on `StaleElementReferenceException`.
4. `modelo/procesar_archivo.py` takes the **first file** found in the `DESCARGA_REPORTE` directory, keeps rows where `Process == "Delivery"` with columns `VIN`, `End_Date`, hands them to `InsertaDatos`, and **always deletes the file** in `finally`.
5. `modelo/inserta_datos.py` connects with pyodbc (`ODBC Driver 17 for SQL Server`), bulk-inserts into `DATASTEWARD..reporte_dda_temp` (`fast_executemany` + `setinputsizes` from `typeToSize`), then `delta_data()` copies only VINs not already in `DATASTEWARD..reporte_dda` (adding `GETDATE()` as `fecha_registro`) and empties the temp table, all in one commit.

Cross-cutting:
- `servicios/resolver_rutas.resource_path` resolves paths against `sys._MEIPASS` when frozen by PyInstaller, else the CWD. Use it for every file path (`.env`, log, download dir, driver), and run from the repo root.
- `vista/logger.Logger` wraps `logging.basicConfig` writing to `ARCHIVO_LOG`. Errors are logged and swallowed throughout rather than propagated, so check the log file to diagnose failures.

## Configuration (.env)

The README has a full `.env` template. Variables read by the code:

- General: `INTENTOS_DESCARGA`, `DESCARGA_REPORTE` (download dir, e.g. `Recursos`), `ARCHIVO_LOG` (e.g. `Log/log.txt`), `RUTA_WEBDRIVER`, `SSL_VERIFY` (`"True"` to activate the Chrome window for the client-certificate prompt via pygetwindow)
- Portal: `RUTA_SPOTFIRE`, `IPN`, `CLAVE`, `ID_INPUT_IPN`, `ID_INPUT_CLAVE`, `XPATH_SIGUIENTE`, `XPATH_INGRESAR_CLAVE`, `XPATH_VERIFICAR`
- Folder XPaths: `XPATH_CARPETA_DA3`, `XPATH_CARPETA_DESING`, `XPATH_CARPETA_COL`, `XPATH_CARPETA_REPORTS`, `XPATH_REPORTS_IN_PROGRES`, `XPATH_CARPETA_DDA`, `XPATH_CARP_COL_DS_DDA_COLOMBIA`
- SQL Server: `SERVIDOR_SQL`, `USUARIO_SQL`, `CONTRASENA_SQL`, `BD_DATASTEWARD`

The `Log/` and `Recursos/` folders are not in git and must be created manually before running.
